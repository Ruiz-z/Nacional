# Guion de demo (5 minutos)

| Tiempo | Paso |
|---|---|
| 0:00–0:30 | **Problema:** la teoría y la práctica del técnico están separadas y hoy su seguimiento es manual (Volvo lo confirmó). |
| 0:30–1:30 | **Diagnóstico** del técnico ficticio `[DEMO]` ya precargado: se muestra su resultado y su ruta. |
| 1:30–3:30 | **Escenario de falla de aislamiento:** el técnico marca la causa en pantalla, ejecuta la acción en el panel, comete un error (por ejemplo torque excesivo), aparece la recuperación y la **brecha**. |
| 3:30–4:00 | **Resumen y reintento** con "¿qué harías distinto?". |
| 4:00–5:00 | **Tablero:** ruta, ganancia, retención simulada (post-test y retest precargados con reloj adelantado) y la fórmula de un indicador. |
| 5:00 | **Cierre** con las tres fases de escalabilidad (el tiempo se recupera acortando el paso del tablero). |

## Plan B
- Falla el panel físico: se usa el panel virtual en pantalla.
- Falla el control: teclado y ratón.
- Falla la laptop: USB con el ejecutable y los datos de demostración en otra máquina.
- No hay asistente LLM: la demo no depende de él.

## Reglas
- Declarar que la retención es simulada con el reloj adelantado.
- Ensayo completo al menos dos veces, con el plan B incluido.
- Tiempos por medir en el primer ensayo; ajustar este guion con los resultados.
